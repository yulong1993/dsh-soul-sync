# dsh-soul-sync — DeepSeek Harness 跨电脑防灾备份与「不断魂」接力套件

> **一句话讲清楚**：你在公司 Windows 电脑上让 DeepSeek Harness 跑了一下午的财报拆解、Python 估值脚本和 Excel 模型，下班合上盖子回家打开 Mac，对话记录、推理心路、脚本和表格全部自动到位——AI 不会像失忆了一样把你刚才干的活说成“据前文所述”，而是顺着刚才的思路以第一人称直接往下接；就算哪天电脑突然断电或主板烧毁，换台新电脑 3 步就能满血复活。

---

## 1. 这是什么 & 核心安全承诺

传统的做法是把整个项目文件夹直接扔进 OneDrive / iCloud，但只要用过就知道坑有多深：Excel 开着就报冲突副本、Git 仓库 `.git` 经常被网盘同步坏、几十 GB 原始数据瞬间塞爆云盘。

`dsh-soul-sync` 采用**「本地工作、金库中转」**设计，给你四条铁律级的安全承诺：

1. **本地工作文件夹绝不放进网盘**：你的项目继续安心放在 `D:\美股分析` 或 `/Users/你/美股分析`，网盘里只放一个专门的加密防灾金库目录（例如 `OneDrive\dsh-vault`）。
2. **不怕 Excel 锁死、不怕 Git 损坏**：
   - 自动忽略 `.git/`、`node_modules/`、虚拟环境、超大原始库与未写完的半截表格；
   - 如果对方电脑推来新版 `.xlsx` 时你正好开着 Excel，它绝不会硬撞报错，而是先安全暂存到 `.dsh-incoming/`，等你关掉 Excel 后一键落位。
3. **可选端到端 AES-256-GCM 加密**：首次安装时设一个口令，所有写进网盘的对话和表格在离开本机前都会加密成密文（网盘和云服务商完全看不见内容），且**派生密钥只保存在本机 `~/.dsh/soul-sync/secret.key`，绝不上传金库**。若在已有多机使用的金库上修改口令，系统会先校验可读设备数防止误输错口令覆盖历史，并支持在面板内一键确认全库口令轮换。
4. **严密隔离敏感凭据**：全程物理跳过 `~/.dsh/.credentials.yaml` 与项目里的 `.env` / 密钥文件；即使选择明文模式，也会自动对会话日志中误贴的常见 API Key（如 `sk-...`、`ghp_...`、`AKIA...`、私钥块）做脱敏打码（仍强烈建议开启端到端加密口令，避免在对话中直接发送生产密钥）。

> **安装目录保留提醒**：DSH 通过符号链接（`link:`）直接挂载你本机的 `dsh-soul-sync` 文件夹，请把本仓库放在长期固定目录（不要放在「下载」目录后误删），否则清理文件夹会导致插件失效。

## 2. 两分钟首次配置

先在你的 OneDrive、iCloud Drive、百度网盘同步盘或 NAS 映射盘里，选好一个空文件夹专门当**防灾金库**（例如 Windows `D:\OneDrive\dsh-vault`、macOS `/Users/你的用户名/Library/CloudStorage/OneDrive-Personal/dsh-vault`）。

> 小贴士：建议右键这个金库文件夹，勾选 **「始终保留在此设备上 / Always keep on this device」**，避免网盘自动清理缓存导致换机时还要等下载。

### 方法 A（最推荐 · 零命令行）：复制一段话发给 DSH，让 AI 自己帮你装

**完全不需要打开终端或记任何命令！** 打开 DeepSeek Harness，把 **[INSTALL_PROMPT.md](./INSTALL_PROMPT.md)** 里的全自动安装提示词复制发给 AI（也可直接复制下面这段精简指令）：

```text
请读取当前（或我指定路径的）dsh-soul-sync 目录里的 INSTALL_PROMPT.md，
按里面的 4 步向导，用大白话一次性向我确认金库路径、是否加密、工作区配对以及是否开启 30 秒防断电快照，
然后自动识别我的操作系统替我跑完安装脚本并核对 doctor 体检通过。
```

回答 AI 问你的 3 个小问题后，等它报「体检通过」，**重启一次 DeepSeek Harness** 就能直接用！另一台电脑重复发同一段话、填同一个口令和同一组路径配对即可。

### 方法 B（备用）：手动一行命令安装

#### Windows 一键安装

先右键退出右下角托盘里的 **DeepSeek Harness**，然后在 PowerShell 里运行（把路径和口令换成你自己的）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-win.ps1 `
  -VaultDir "D:\OneDrive\dsh-vault" `
  -Passphrase "你的专属同步口令" `
  -Map "D:\美股分析::/Users/你的Mac用户名/美股分析"
```

- 不想敲参数？直接运行 `powershell -ExecutionPolicy Bypass -File .\scripts\install-win.ps1` 进入中文问答向导。
- 多个常用项目可传多个 `-Map`（例如 `-Map "D:\美股分析::/Users/me/美股分析","D:\A股跟踪::/Users/me/A股跟踪"`）；在一端绑定后会自动同步至加密金库供另一端接收。
- 不想设加密口令，把 `-Passphrase "..."` 换成 `-NoPassphrase`。
- 如果本机已有大量旧对话、只想安装后先到面板手动挑选要同步的项目，可追加 `-Scope selected`。
- 稳妥派不想开启运行中每 30 秒步级快照，可追加 `-DisableStepSync`（仅在每轮对话结束时安全同步）。

#### macOS 一键安装

把 `dsh-soul-sync` 文件夹拷贝到 Mac，彻底退出 DeepSeek Harness（`Cmd+Q`），打开「终端」运行：

```bash
bash ./scripts/install-mac.sh \
  --vault "/Users/你的Mac用户名/Library/CloudStorage/OneDrive-Personal/dsh-vault" \
  --passphrase "你的专属同步口令" \
  --map "D:\美股分析::/Users/你的Mac用户名/美股分析"
```

- 稳妥派如需关闭运行中每 30 秒步级快照，追加 `--disable-step-sync` 即可；如需首启仅启用精选模式，追加 `--scope selected`。

> **双端只需保持一致的一件事**：填**同一个防灾金库网盘目录**和**同一个加密口令**（工作区路径映射 `--map` 完全可选——未绑定映射的工作区自动创建独立同名目录并随身同步 `outputs/` ≤30MB；如需同步根目录脚本/表格与 Excel 锁保护，在任意一端的 **「设置 → Soul Sync 跨机迁移」** 面板绑定一次一一对应即可跨机生效）。

安装脚本会自动帮你完成配置生成、写入跨平台 `AGENTS.md` 规则、安装 `soul-handoff` 技能、注册 `web`/`desktop` 两个 profile 并跑一遍 `doctor` 体检。重新打开 DeepSeek Harness 即可无感使用！

## 3. 日常怎么用（平时 0 命令全自动！）

### 零感知自动防灾与跨机续聊（平时什么都不用敲）

- **每轮结束自动加密入库（始终常开）**：每聊完一轮，完整原装对话、原生思维链、附图附件以及 `outputs/` 下的报告/表格/脚本自动静默同步到金库。
- **启动秒拉 + 后台每 15 秒无感刷新侧边栏**：另一台电脑打开 DeepSeek Harness（哪怕一直开着没关，也会每 15 秒轻量检测网盘新快照），**按最后发言时间排序将最新对话置顶出现在左侧会话列表第 1 条**，同时联动置顶刚更新的工作区，直接点开就能顺着上一句继续聊！
- **多工作区自由选择（「自动同名生成」vs「严格一一对应」+「按需勾选迁移」）**：
  - 点击 DSH 左下角 **「设置 → Soul Sync 跨机迁移」** 即可打开原生可视化面板：
    - **文件夹对应方式二选一**：支持 **✨ 自动同名生成并对应**（已配对走一一对应，未配对目录自动匹配本机同名工作区或在 `~/Documents/deepseek-harness/workspaces/<项目名>` 自动建独立同名目录，绝不把多个不同工作区混进同一个 `default-workspace`）或 **🔗 严格仅同步手动一一对应的文件夹**；
    - **日常自动推送范围二选一**：支持 **🟢 自动同步活跃对话（自动剔除 0 轮空壳与命令窗口）** 或 **🎯 精选白名单模式（本机仅自动推送勾选的工作区与对话，其余 100% 留在单机本地；对端主动推入金库的对话仍可正常接收）**；
    - **选择性迁移工作台**：支持按工作区或单条对话勾选加密推送 / 从金库按需拉取 / 从金库撤回或屏蔽单条对话（拉取时可当场改选落入本机任意目录、自动新建同名目录或自定义路径，并可一键保存为永久对应）。
- **内置「金库连接与加密基础设置」卡片**：随时可在 DSH 左下角 **「设置 → Soul Sync 跨机迁移」** 顶部直接修改金库路径、加密口令（支持错口令自动诊断与自助修复）、本机昵称与 30 秒步级防断电快照开关。

### 可选 `/soul` 快捷指令（毫秒级秒回，空白欢迎页也可直接展示）

平时完全不用敲 `/soul`；只在你需要查看体检卡或给超长对话瘦身时按需使用：

- **查体检状态 / 查 Excel 锁**：`/soul 帮我看看现在同步正常吗` 或 `/soul status`
- **立即双向同步**：`/soul 同步一下`（毫秒级拉取远端更新 + 推送本机最新进度）
- **超长对话保尾无损压缩（不断魂）**：`/soul 帮我无损压缩一下`、`/soul 整理一下上下文`、`/soul compact 3`
  - 只压缩更早的对话，完整保留末尾最近 3 轮（支持自定义轮数）原装人类提问、AI 原生思维链与工具调用配对；
  - 多次连续压缩内置**跨代钢印账本（带议题作用域隔离）+ 滑动金字塔 + 体积护栏**，核心公理与精确阈值跨代不衰减，用户显式翻案才原地更新；
  - 随时需要核对被折叠的早期数字、报错或思维链原文时，AI 可直接调用内置只读工具 `soul_recall_history` 一键回捞底稿，绝不凭记忆乱猜。
- **下班换电脑交接日记（可选）**：
  ```text

  ```
  检查 Excel 占锁、让 AI 写一段 150~250 字的第一人称《中场交接心路日记》（含 Flash 看图 → V4Pro 视觉文字桥接）并释放接力棒。
- **把手工文件加进同步**：`/soul 把 outputs/估值表.xlsx 加进同步`、`/soul 帮我把 notes/核心假设.md 也加进同步`
- **开关 30 秒防断电快照**：`/soul 关闭30秒快照`、`/soul 开启30秒快照`

## 4. Python 脚本、Excel 表格与报告怎么同步

为了既不错过任何劳动成果，又绝不把几十 GB 原始历史库拖进网盘，本套件按**「来源账本」**精准同步：

| 文件类型 | 是否自动同步 | 说明 |
| --- | :---: | --- |
| `outputs/` 目录下的所有报告、图表、估值表 | 自动同步 | 推荐约定：最终成果一律放 `outputs/`（未绑定映射的自动同名工作区仅同步 `outputs/`，单文件 ≤10MB、单会话 ≤30MB） |
| 已绑定一一对应工作区中 AI 创建/修改的 `.py` / `.xlsx` / `.md` 等 | 自动同步 | 绑定一一对应后全目录追踪，后续手工在 Excel 里的修改也会持续同步并受 Office 防锁保护 |
| `.work/` 目录里的临时草稿与缓存 | 自动忽略 | 脏数据和中间过程不污染同步 |
| 已纳入 Git 管理的源码文件（`git ls-files`） | 自动忽略 | 交给 Git 管，绝不跟网盘打架 |
| 原本就在目录里的存量历史大文件 | 自动忽略 | 不会把几十 GB 老资料搬进金库 |
| `.env`、含 `sk-` 密钥文件、破损半截 `.xlsx`/`.pdf` | 自动拦截 | 保护隐私并防止半成品覆盖好版本 |

### 几个超实用的日常技巧

- **手工建的文件也想同步**：直接发 `/soul 把 notes/核心假设.md 加进同步`（或 `/soul keep notes/核心假设.md`），就会立刻记入账本并同步到另一台电脑。
- **Excel 没关导致占锁怎么办**：不用慌！远端推来的新版表格会自动暂存在工作区里的 `.dsh-incoming/` 目录。你关掉 Excel 后，发一句 `/soul 我把Excel关了帮我把暂存文件落位`（或 `/soul pull`），它就会自动落位并清空 `.dsh-incoming/`。
- **两台电脑离线同时改了同一张表怎么办**：绝不互相覆盖！本机版本原样保留，另一台电脑的版本会并列保存成 `估值表 (来自家里Mac 2026-11-24).xlsx`，发一句 `/soul 帮我对比一下冲突副本和现在的表差在哪并合并` 就能让 AI 协助对照合并。
- **误删文件能找回吗**：对端删除文件时，本机不会直接永久粉碎，而是先移到 `~/.dsh/trash/<工作区>/` 保留 **14 天**，随时可捡回来。

## 5. 电脑突然断电 / 主板烧毁急救指南

如果公司电脑彻底报废，换一台全新电脑（无论 Windows 还是 Mac），只需要 **3 步** 满血复活：

1. **安装网盘客户端并等防灾金库同步完成**（确保金库目录里的 `blobs/` 和 `devices/` 已下载到本地）。
2. **安装 DeepSeek Harness 并完成插件配置**（用 [INSTALL_PROMPT.md](./INSTALL_PROMPT.md) 发给 AI 自动装，或手动跑一遍一键安装脚本，填入同样的金库路径、同样的加密口令和新电脑的工作区路径映射）。
3. **执行离线全量恢复**（如果还没开 DSH，直接终端运行一行即可）：
   ```powershell
   node .\bin\dsh-soul.js pull
   ```
   全部历史会话、子代理推演、附图附件、全局 `AGENTS.md` 规则以及各工作区里的 Python 脚本、Excel 估值表和报告都会自动还原到位！

## 6. 配额调整与命令速查表

默认安全配额：单文件上限 **30 MB**、单工作区上限 **500 MB**、历史版本保留 **10 份**、步级防灾快照 **默认开启（30 秒节流，可独立关闭）**、软删除回收站保留 **14 天**。你可以随时用自然语言或参数命令动态修改，不用重启。

| `dsh-soul config [key=value ...]` | 查看或修改 `stepSync`、`stepSyncEnabled`、`maxFileMB`、`maxWorkspaceMB`、`retainSnapshots`、`stepSyncIntervalMs`、`trashRetentionDays`、`deviceLabel`、`vaultDir` |
| `dsh-soul doctor` | 全面自检配置、金库可读写性、加密密钥、技能、规则块与 DSH 插件注册状态 |
| `dsh-soul watch [--interval-ms 60000]` | 启动轻量级后台守护进程，定时备份会话与监听工作区产出物变更 |
